# word-hoard dependencies.
#
# Pinned from `pip freeze` in the project venv. First pinned 2026-08-26, and
# extended 2026-08-29 when slice step 6 brought in the web layer. Before the
# first successful install the versions were deliberately left open, because a
# guessed pin looks authoritative and is not.
#
# Set up from scratch:
#   python -m venv .venv
#   .venv/Scripts/python.exe -m pip install \
#       --trusted-host pypi.org --trusted-host files.pythonhosted.org \
#       -r requirements.txt
#
# The --trusted-host flags are the bootstrap for the Netskope problem described
# below. They are needed on the first install only, because pip itself has to
# reach pypi.org before pip-system-certs can be installed to fix it.

# --- environment ---

# Makes Python trust the Windows certificate store. Required on this machine
# because HTTPS is intercepted and re-signed by Netskope, which browsers accept
# (the root CA is in the Windows store) but Python via certifi does not. Without
# it, any HTTPS call fails with CERTIFICATE_VERIFY_FAILED.
# See the Environment section of CLAUDE.md.
pip_system_certs==5.3

# --- scheduling ---

# FSRS reference implementation. Depended on rather than reimplemented from the
# paper: the algorithm is the core value of this project and a subtle
# reimplementation bug would be invisible for months.
#
# Note the distribution name. The project is called py-fsrs on GitHub, but the
# package on PyPI is plain `fsrs`, and `pip install py-fsrs` fails with "no
# matching distribution found" rather than anything that hints at the real name.
#
# 6.x matters: this version implements learning steps and relearning steps
# itself, via Scheduler(learning_steps=...) and Card.step. The project had
# planned to write that state machine by hand, and no longer does. Do not
# downgrade below 6 without restoring it. See wordhoard/scheduler.py.
fsrs==6.3.2

# --- web layer, used ONLY by web/ and scripts/serve.py ---
#

# the review history and the scheduler are the long-lived assets; the routing
# layer is the most replaceable part of the system, so it is kept at the edge.
# There is a grep in the step 6 verification that checks this holds.
