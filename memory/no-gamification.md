word-hoard deliberately keeps the four learning modes from Duolingo (typing,
reading, listening, speaking) and drops every gamified element. No experience
points, no streak counters, no leaderboards, no mascots, no badges, no
notifications designed to pull someone back. No polished or animated UI either:
function over form, at least until the engine is right.

**Why:** This is not a preference to be revisited once the core works. It is the
reason the project is being built at all rather than a subscription being paid.
The effort belongs in honest progression tracking, not in anything engineered to
drive return visits.

**How to apply:** Do not suggest or add these features, including in a
well-meant "this would make it more motivating" form. If something genuinely
needs a progress indicator, prefer an honest diagnostic (what is due, how
accuracy differs by exercise type) over a reward mechanic. See
[[vertical-slice-first]].
